# SDLC Summary — Digital Recipe Organizer (RecipeBox)

1. **Planning:** Define the goal: a simple app to organize recipes.
2. **Requirements:** Add, view, search, filter, edit, and delete recipes; validate required data.
3. **Design:** Browser interface, Flask backend, SQLite database, Recipe entity.
4. **Implementation:** Python/Flask, HTML templates, CSS, SQLite.
5. **Testing:** Automated tests for page loading, adding, searching, and invalid input; manual checks for filtering/editing/deleting.
6. **Deployment:** Install requirements and run `python app.py`; open `http://127.0.0.1:5000`.
7. **Maintenance:** Fix defects, back up data, update dependencies, and add requested features.

See `SDLC_Lifecycle_Document.docx` for the full report and demonstration script.
